CSS Selectors – HTML Reference

A static reference for understanding selectors and HTML parent–child relationships.

1. HTML hierarchy

Read the indentation: elements further to the right are nested inside their parent element.

<body>
<header> Page heading </header>
<main>
<form id="login-form">
<input id="username" class="form-control" type="text" name="user">
<input id="user-password" class="form-control" type="password" name="password">
<button class="btn primary">Login</button>
<a href="/forgot-password">Forgot password</a>
</form>
<section id="profile">
<h2>Profile details</h2>
<input id="email" class="form-control" type="text" name="email">
<button class="btn">Save</button>
</section>
<section>
<ul id="items">
<li>First item</li>
<li>Second item</li>
<li>Third item</li>
</ul>
</section>
</main>
<footer> Page footer </footer>
</body>

2. Basic selectors

#usernameID selector – selects the element with id="username".
.form-controlClass selector – selects all elements with the class form-control (three inputs).
inputTag selector – selects all <input> elements.
input[type="password"]Attribute selector – selects input elements with type="password".

3. Combining selectors

input#usernameAn input element whose ID is username.
input.form-controlInput elements that have the form-control class.
button.btn.primaryA button that has both the btn and primary classes.
input[type="text"][name="user"]An input matching both attributes: type is text AND name is user.

4. Relationships between elements

#login-form inputDescendant – all input elements anywhere inside the login form.
#login-form > inputDirect child – input elements that are immediate children of the login form.
input + buttonAdjacent sibling – a button immediately following an input with the same parent.
input ~ buttonGeneral sibling – buttons that follow an input and share the same parent.

5. Attribute selectors

input[id^="user"]Starts with (^=) – the id attribute begins with "user".
input[id$="name"]Ends with ($=) – the id attribute ends with "name".
input[id*="user"]Contains (*=) – the id attribute contains "user" anywhere.

6. Pseudo-classes

ul li:first-childSelects the first <li> child of a <ul>.
ul li:nth-child(2)Selects the second child element of the <ul> (the second list item here).

Quick reminder

#id selects by ID · .class selects by class · tag selects by element name.

A B means B is anywhere inside A · A > B means B is a direct child of A.

A + B means B is the next sibling · A ~ B means B is a later sibling.
